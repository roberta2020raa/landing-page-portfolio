# 💻 Landing Page — Roberta Dev

Landing Page desenvolvida para apresentar minha trajetória, habilidades e projetos como desenvolvedora Front-End.

Este projeto também faz parte da minha jornada prática de aprendizado, sendo utilizado para aplicar conceitos de HTML, CSS, JavaScript, Git e GitHub em um projeto real e em constante evolução.

## 📌 Sobre o projeto

A Landing Page foi construída do zero com foco em estrutura, organização do código, estilização e responsividade.

Além do desenvolvimento Front-End, o projeto é utilizado como laboratório prático para aprender e aplicar um fluxo de versionamento próximo ao utilizado em projetos profissionais.

Durante seu desenvolvimento, estou praticando:

- criação e organização de arquivos;
- desenvolvimento de seções e componentes;
- organização dos estilos em arquivos CSS;
- responsividade;
- controle de versões com Git;
- utilização do GitHub;
- criação e gerenciamento de branches;
- Conventional Commits;
- Pull Requests;
- merge e sincronização entre ambiente local e remoto.

## 🎯 Objetivos do projeto

- Praticar desenvolvimento Front-End na construção de um projeto completo.
- Consolidar conhecimentos de HTML e CSS.
- Desenvolver layouts responsivos.
- Aprender a organizar e evoluir um projeto de forma incremental.
- Aplicar boas práticas de versionamento.
- Desenvolver familiaridade com o fluxo de trabalho do Git e GitHub.
